# 选词朗读 SelectSpeak

Android app with ACTION_PROCESS_TEXT selection-menu integration and TextToSpeech. Language preference en-US or en-GB; speech rate configurable. Offline if your Android speech engine supports offline playback. No network permission and no API key.

## APK

See GitHub Actions -> Build SelectSpeak APK -> successful run -> Artifacts -> SelectSpeak-debug-apk. Download artifact ZIP and unzip to find app-debug.apk.

ChatGPT may use its own selection menu and decline to surface third-party Android actions; this app cannot force that integration. Test in a browser or notes app first.
